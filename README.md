# Elitlig Araçlar — Mac ve Windows uygulaması

Elitlig yönetim panelindeki **Araçlar** bölümünün Mac için yazılmış bağımsız uygulaması.
Siteyi bir pencerede açmaz: kendi arayüzü vardır ve Elitlig sunucusuyla doğrudan konuşur.
Veriler sitedekiyle aynıdır; uygulamada yapılan her değişiklik sitede, sitede yapılan her değişiklik
uygulamada görünür.

## Web sitesinde olmayan masaüstü özellikleri

- **Bir kez giriş, 3 ay kullanım.** Oturum 90 gün açık kalır. Oturum bilgisi Mac'in Anahtar Zinciri
  ile şifrelenir; diskte düz metin olarak durmaz.
- **İnternet yokken de çalışır.** Son görülen veriler diskte saklanır. Bağlantı yokken eklenen not,
  görev, etkinlik, muhasebe kaydı, kişiler ve projelerdeki görüşme sonuçları kuyruğa alınır; bağlantı gelince sırayla gönderilir.
- **Her yerden hızlı kayıt: ⌃⌥N.** Hangi uygulamada olursanız olun küçük bir pencere açılır:
  görev, not, etkinlik ya da gider tek satırda kaydedilir. “yarın 14:00 sahayı ara !” gibi yazılan
  tarih, saat ve öncelik kendiliğinden anlaşılır.
- **Her araca masaüstünden: ⌃⌥O hızlı geçiş**, Dock simgesi menüsü (Mac) / görev çubuğu atlama listesi
  (Windows), menü çubuğunda *Araçlar*, Başlatıcı ve Araç çubuğu widget'ları, `elitlig-araclar://` bağlantıları.
- **Mac bildirimleri.** Ajanda hatırlatmaları, zamanı gelen görevler ve vadesi yaklaşan / geciken düzenli ödemeler (fatura, maaş, kira, taksit) pencere kapalıyken de bildirim olarak gelir.
- **Menü çubuğu simgesi.** Çalışan odak sayacının kalan süresi, yaklaşan etkinlikler ve açık iş sayısı.
- **Dock rozeti.** Bugün ve gecikmiş iş sayısı, okunmamış mesajlar (üye mesajları dahil) ve bekleyen talepler.
- **Talep bildirimleri.** Yeni talep gelince (socket “admin:requests”) pencere arka plandaysa Mac bildirimi
  gelir; tıklayınca Talepler ilgili kategoride açılır. Menü çubuğu menüsünde bekleyen talep sayısı.
- **Mesaj bildirimleri.** Pencere arka plandayken gelen mesaj Mac bildirimi olarak gelir; tıklayınca
  sohbet açılır. Sessize alınan sohbetler bildirim göndermez. Menü çubuğu menüsünde okunmamış mesaj sayısı.
- **Komut paleti: ⌘K.** Araçlara geçiş, hızlı eylemler (yeni sohbet, yeni grup…) ve sohbet, mesaj gönderilecek kişi, görev, not, kişi, proje, aranacak kişi, tablo ve muhasebe kayıtlarında arama.
- **Dosyalar doğrudan Mac'e.** Excel, CSV, PDF, `.ics`, `.vcf` ve Markdown dışa aktarma; Excel ve CSV açma.
- **Raflar: ⌃⌥T / ⌃⌥S / ⌃⌥A.** Her yerden ekran görüntüsü, pano ve bağlantı rafları; raflarda arama; işaretçinin altındaki ekranı yakalayıp kırpma (bkz. Ekran Görüntüleri ve Pano).
- **Dosya Araçları ve Float.** Dosya dönüştürme / düzenleme uygulama içinde; Float rafındaki dosyalar başka uygulamalara sürüklenir.

## Kurulum

### Mac

1. [Releases](../../releases/latest) sayfasından `Elitlig-Araclar-<sürüm>.dmg` dosyasını indirin.
2. Dosyayı açın ve **Elitlig Araçlar**'ı **Applications** klasörüne sürükleyin.
3. Uygulama Apple Developer sertifikasıyla imzalı olmadığı için macOS ilk açılışta engeller. Bir kez şunu yapın:

   ```bash
   xattr -cr "/Applications/Elitlig Araclar.app"
   ```

   ya da uygulamayı açmayı deneyip **Sistem Ayarları → Gizlilik ve Güvenlik → Yine de Aç**.
4. Elitlig yönetim hesabınızla giriş yapın.

Apple Silicon ve Intel Mac'lerde çalışır (evrensel uygulama). macOS 12 ve üzeri gerekir.

### Windows

1. [Releases](../../releases/latest) sayfasından `Elitlig-Araclar-Setup-<sürüm>.exe` dosyasını indirip çalıştırın.
2. Uygulama henüz kod imzalı olmadığı için Windows SmartScreen "Windows bilgisayarınızı korudu"
   diyebilir: **Ek bilgi → Yine de çalıştır**.
3. Kurulum klasörünü seçin (varsayılan: `%LOCALAPPDATA%\Programs\Elitlig Araclar`, yönetici izni
   gerekmez). Masaüstü ve Başlat menüsü kısayolları oluşturulur; kaldırmak için
   **Ayarlar → Uygulamalar → Elitlig Araçlar → Kaldır**.
4. Elitlig yönetim hesabınızla giriş yapın.

Windows 10 / 11, 64 bit. Kurulumsuz kullanım için `Elitlig-Araclar-<sürüm>-win-x64.zip` açılıp
`Elitlig Araclar.exe` çalıştırılabilir.

- **Yayın Stüdyosu** Windows'ta da ffmpeg ile gelir (`resources\ffmpeg\ffmpeg.exe`, FFmpeg 7.1.1,
  Gyan Doshi "essentials" derlemesi, GPLv3, SHA-256 doğrulamalı). Donanım kodlayıcı şu sırayla
  denenir: NVIDIA **NVENC** → Intel **Quick Sync** → AMD **AMF** → **Media Foundation** → yazılım (x264).
  Ekran kartı sürücüsü eskiyse donanım kodlayıcı açılmaz ve x264'e geçilir; sürücüyü güncellemek
  işlemci yükünü azaltır.
- **Kamera / mikrofon:** **Ayarlar → Gizlilik ve güvenlik → Kamera** (ve **Mikrofon**) altında
  "Masaüstü uygulamalarının erişmesine izin ver" açık olmalıdır. Ekran paylaşımı için ayrıca izin gerekmez.
- Hızlı kayıt kısayolu Windows'ta da **Ctrl+Alt+N**'dir; menüdeki **⌘** kısayolları **Ctrl** ile çalışır.

## Projeler

Bir projenin tüm ihtiyaçları, süreçleri ve cevapları tek yerde: kimin aradığı, ne cevap alındığı,
kimin tekrar aranacağı, satışı kapananlar ve her adımın durumu. Veriler sitedeki **Araçlar → Projeler**
ile aynıdır (`/api/tools/projects`).

- **Şablonlar.** Yeni projede şablon seçilir: **Organizasyon sezonu** (kendi iş akışı tablonuzdaki
  208 görev, 19 aşamada, “Ana Sorumlu Personel” rolleriyle), **Satış süreci** ya da **Boş proje**.
  Hiçbir adım sabit değildir: aşama ve adım eklenir, yeniden adlandırılır, renklendirilir, sürükle-bırakla
  aşama içinde ve aşamalar arasında taşınır, silinir. Bir proje **şablon olarak kaydedilip** yeni
  projelerde kullanılabilir ya da kopyalanabilir.
- **Süreç.** Aşamalara göre gruplu adımlar; hızlı durum (Bekliyor, Devam ediyor, Yanıt bekleniyor,
  Takıldı, Tamamlandı, Gerek yok), sorumlu roller, atanan kişi, son tarih (geciken kırmızı), öncelik,
  kontrol listesi ve soru sayısı. Adım çekmecesinde her alan düzenlenir: **Sonuç / cevap**, açıklama,
  bağlantılar (site yolları — ör. `/editor/maclar` — tarayıcıda elitlig.com'da açılır), adımın soruları,
  notları ve geçmişi. “Yapılacaklara gönder” adımı göreve çevirir.
- **Araçlar adımın içinde.** Adıma bir araç bağlanır. “Potansiyel müşterilerin aranması” gibi bir
  adımda **Aracı aç**, Kişiler (CRM) panelini o adımın üstünde, ilgili aşamaya süzülmüş olarak açar:
  adımdan çıkmadan kişi eklenir, aranır, sonucu kaydedilir. Soru-cevap, portföy ve iletişim geçmişi de
  aynı biçimde açılır; Yapılacaklar, Ajanda, Not Defteri, Tablolar, Muhasebe, Rehber, Hesap Araçları ve
  Odak Sayacı bağlı adımlarda ilgili araca geçilir.
- **Kişiler (CRM) ve görüşme sonuçları.** Tablo ya da aşama panosu (sürükleyip aşama değiştirme),
  “Bugün aranacak / Gecikmiş / Aksiyonsuz” süzgeçleri, hızlı ekleme. Kişi çekmecesinde tek tıkla
  **Ara**, **WhatsApp** (wa.me/90…), **E-posta**; **hızlı sonuç düğmeleri** (“Ulaşılamadı”, “Geri
  dönecek”, “Tekrar aranacak”…) aramayı tek tıkla kaydeder, kişiyi ilgili aşamaya taşır ve sonraki
  aramayı planlar (sonuçlar ve gün sayıları proje ayarlarından düzenlenir). Sonraki aksiyon Ajanda'ya
  eklenebilir. Tüm projelerin aranacakları, adımlarım ve açık sorular **Takip** bölümünde ve Bugün
  ekranındaki “Projelerde bugün” kartında toplanır.
- **Tedarik görüşmeleri.** Kişiler sekmesinde “Müşteri görüşmeleri | Tedarik görüşmeleri” anahtarı.
  Tedarikçiler (tesis, kupa/madalya, baskı, yayın…) kendi aşamalarıyla (Tedarikçi adayı → Fiyat istendi
  → Fiyat alındı → Değerlendiriliyor → Pazarlık → Anlaşıldı / Vazgeçildi) izlenir; “Fiyat alındı”
  teklif tutarını sorar. Aynı konudaki teklifler çekmecede **fiyat karşılaştırması** olarak ucuzdan
  pahalıya sıralanır, en uygunu işaretlenir. “İşlemi tamamla → Gidere yaz” anlaşılan tutarı projenin
  bütçesine gider olarak yazar (hesap, Bekliyor/Ödendi, vade). Adımdaki “Tedarik görüşmeleri” aracı
  (ör. “Tesis araştırması”, “Ödül / kupa / madalya siparişlerinin verilmesi”) listeyi adımın içinde açar.
- **Bütçe.** Projenin gelir ve gider kalemleri: tahmini/gerçek tutar, durum (Tahmin, Bekliyor, Ödendi /
  Tahsil edildi, İptal), vade, kategori, bağlı kişi/tedarikçi ve adım. Tek tıkla “Ödendi / Tahsil
  edildi” kalemi bağlı muhasebe hesabına işler (“Hesaba işlendi: …”) ve hesap bakiyesi anında değişir.
  Varsayılan proje hesabı ve bu hesabın yetkilileri (“Proje ekibine yetki ver” dahil) Ayarlar → Bütçe ve
  muhasebe'den yönetilir; buradan projeye özel ortak hesap da açılır. Bütçe adımları (“Tahmini gider
  bütçesinin hazırlanması”…) Bütçe panelini o adıma süzülmüş açar.
- **Portföy.** “Satışı kapat” kişiyi kazanıldı aşamasına alır, portföye yazar (kategori, tutar) ve
  istenirse bütçeye gelir kaydı açar. Portföy proje içinde ve tüm projelerde (genel) görülür; elle de
  eklenir.
- **Rehberden ekle.** Rehberim, Elitlig üye rehberi (“Üyeleri görüntüleme” yetkisiyle) ve portföyden
  arama, kategori süzgeci ve çoklu seçimle kayıtlar projenin müşteri ya da tedarik listesine
  kopyalanır; listede olanlar işaretlenir. Proje listesi Rehber'e yazılmaz, Rehber de proje listesine
  karışmaz.
- **Excel.** “Excel'den adım aktar” kendi tablonuzu okur: **Görev / İş Kalemi**, **Ana Sorumlu
  Personel** ve isteğe bağlı **Aşama** sütunları (aşama sütunu yoksa BÜYÜK HARFLİ başlık satırları
  aşama sayılır). Kişiler de Excel/CSV'den aktarılır (aynı telefon/e-posta atlanır).
  Adımlar, kişiler ve portföy Excel/CSV olarak dışa aktarılır.
- **Ekip.** Proje sahibi yönetim kullanıcılarını düzenleyici ya da izleyici olarak ekler; izleyiciler
  yalnız görür.
- **Çevrimdışı.** Projeler ve son görülen hâlleri önbellekten açılır. Bağlantı yokken görüşme sonucu,
  not, soru ekleme/cevaplama ve adım/kişi güncellemeleri kuyruğa alınır (kişinin aşaması ve sonraki
  araması ekranda hemen güncellenir); bütçe kalemi ekleme ve “Ödendi” yapma da kuyruğa alınır.
  Proje, aşama, adım ve kişi oluşturma ya da silme, görüşme kapanışı ve rehberden aktarma bağlantı
  ister ve açık bir uyarı verir.

## Mesajlar

Sitedeki ve mobil uygulamadaki sohbetle aynı veridir (`/api/chat/*`). Yönetim hesabı ekip
arkadaşlarıyla (yönetim), takım başkanlarıyla, oyuncularla ve üyelerle birebir yazışır, bunları
karıştırarak grup kurar; üyeler yönetimin başlattığı sohbete yanıt verir.

- **Görünüm (2.8).** Güncel WhatsApp masaüstü düzeni, Elitlig renkleriyle: en solda ikon rayı
  (Sohbetler, Gruplar, Üye mesajları, Yıldızlı, Arşiv; altta Kayıtlar, Ayarlar ve profil), büyük
  başlıklı liste, yuvarlak arama ve süzgeç hapları (Tümü / Okunmamış / Sabitlenen / Gruplar), ferah
  satırlar; futbol çizimli sıcak gri sohbet duvarı, kuyruklu pastel balonlar, yüzen yuvarlak yazma
  çubuğu, mikrofon ↔ gönder dönüşümü, renkli “+” menüsü; açık ve koyu tema (koyuda Elitlig'in
  patlıcan tonları); dar pencerede liste ↔ sohbet ekranları (geri düğmesi). **Ayarlar**: kimler size
  yazabilir, engellenenler, kısayollar.
- **Düzen.** Solda sohbet listesi (arama — sohbetlerde ve mesajlarda —, süzgeçler, arşiv satırı;
  sabitlenenler üstte, son mesaj, gönderen, ✓ / ✓✓ / mavi ✓✓, saat, okunmamış rozeti,
  “okunmadı” noktası, sessiz simgesi, taslak, yazıyor…, çevrimiçi noktası, takım rozeti); ortada sohbet
  (gün ayraçları, gönderen adı renkli balonlar, yanıt alıntısı — tıklayınca asıl mesaja gider —,
  iletildi / düzenlendi etiketi, tepkiler, fotoğraf albümü, belge, sesli mesaj, anket, konum, sistem
  satırları, silinen mesaj); sağda kişi / grup bilgisi, medya-belgeler-bağlantılar, yıldızlılar, arama.
- **Mesaj eylemleri** (üzerine gelince ⌄ ya da sağ tık): tepki (👍❤️😂😮😢🙏), yanıtla, kopyala, ilet
  (çoklu seçim, en çok 5 sohbete), yıldızla, sabitle, düzenle (kendi metin mesajı, 15 dk), bilgi
  (kimler okudu), herkesten sil.
- **Yazma alanı.** Emoji, “+” ek menüsü (fotoğraf, belge, anket, konum, ses kaydı; yönetimde
  Elitlig içerikleri), sesli mesaj kaydı, yanıt ve
  düzenleme çubuğu, grupta @bahsetme önerisi, Enter gönderir / ⇧Enter yeni satır, ↑ son mesajı
  düzenler; sohbet başına taslak; görsel yapıştırma ve sürükle-bırak (en çok 25 MB).
- **Yeni sohbet / yeni grup.** Rehber bölümleri: Yönetim, Takım başkanları, Oyuncular, Üyeler
  (aramayla); her kişide takım adı öne çıkar. Grupta ad, fotoğraf, açıklama, “yalnız yöneticiler
  yazar / düzenler”. Rehber → Takımlar'daki **Takımla grup kur** başkanlar ve hesaplı oyuncularla grubu
  hazırlar.
- **Grup bilgisi.** Fotoğraf, ad, açıklama, ayarlar, üyeler (grup yöneticisi rozeti), üye ekle /
  çıkar, yönetici yap, gruptan çık. **Kişi bilgisi:** takım, rol, telefon ve e-posta (üye rehberi
  yetkisiyle), ara, WhatsApp, e-posta, ortak gruplar, sessize al, engelle, şikayet et.
- **Canlı bağlantı ana süreçte.** Socket.IO bağlantısı uygulamanın ana sürecinde açılır (jeton
  arayüze verilmez), kopunca kendiliğinden artan aralıklarla yeniden bağlanır. Bağlantı yokken
  sohbet listesi 15 sn'de, açık sohbet 6 sn'de bir yenilenir; yeni mesaj bildirimi bu yoklamayla da
  gelir. Ekler ana süreçten yüklenir; sohbet medyası diskte önbelleklenir ve çevrimdışı da açılır.
- **Çevrimdışı.** Sohbetler ve son mesajlar önbellekten okunur. Bağlantı yokken yazılan metin mesajı
  saat simgesiyle kuyruğa alınır ve bağlantı gelince gönderilir (sunucu `client_id` ile çift kaydı
  önler); tepki, dosya, anket, grup işlemleri bağlantı ister.
- **Kısayollar.** ⇧⌘M Mesajlar, ⌘N yeni sohbet, ⇧⌘N yeni grup, ⌘F sohbette ara, ⌥⌘↓ / ⌥⌘↑ sonraki /
  önceki sohbet, Esc paneli kapatır.
- **Sesli arama** masaüstünde henüz yok (düğme kapalı); aramalar mobil uygulamadan ya da siteden yapılır.

### Hazır içerikler (yönetim hesapları)

“+” menüsündeki **Elitlig içerikleri** bölümünden ya da grup başlığındaki ✨ düğmesinden gönderilir
(sunucu: `/api/chat/content/*`, `services/chat/chatContent.js`). Üye mesajları ortak kutusunda yoktur.

- **Günün maçları.** Gün seçilir (varsayılan bugün, ‹ › ile önceki / sonraki gün), o günün maçları lige
  göre gruplu ve hepsi seçili gelir; not eklenir, sağda canlı önizleme. Sohbette fikstür kartı: lig
  etiketi, saat hapı, takımlar (oynandıysa skor), saha, atanmış görevliler (spiker, reji, hakem…);
  maça tıklayınca sitede açılır; **Talip anketi aç** aynı maçlarla görev anketini hazırlar.
- **Ben talibim.** Görevler (spiker, reji, hakem, fotoğrafçı, sağlıkçı) ve maçlar seçilir; başlık,
  not, son tarih. Kart maça göre gruplu, her görev bir satır: talip olanların avatarları, büyük
  **Talibim** düğmesi (üzerine gelince **Vazgeç**), görevli atandıysa yeşil rozet. `staff.assign`
  yetkisi olan **Görevlendir** ile talip olanlardan birini maça yazar (maç ekibine kaydolur); anketi
  gönderen kapatır / yeniden açar. Değişiklikler herkese canlı yansır.
- **Haftanın Enleri.** Yapılacaklar'daki aday önerisi akışının aynısı (`todos.assign`): hafta, lig,
  sezon, tarih aralığı, kategoriler, kadro, son tarih, not. Sohbetteki yönetim ekibine aday öneri
  kartı, gönderene koordinasyon kartı açılır. Kupa kartında kategoriler, “3/5 öneri geldi” ilerlemesi
  ve öneren avatarları; **Adaylarını öner** Yapılacaklar'ın öneri düzenleyicisini, koordinatördeki
  **Önerileri topla** öneri panosunu (kaydet, yayına al) pencerede açar.

### Üye mesajları (ortak gelen kutusu)

Tek mesajlaşma sistemi: eski “Mesaj Yönetimi” / yönetim gelen kutusu ekranı yerine üyelerin
**ElitLig Yönetimi** sohbetleri de Mesajlar'dadır. Yalnız `messages.view` yetkisi olan yöneticiye
görünür (yetkiler oturumdaki kullanıcıdan ve açılışta `/api/users/verify`'dan okunur; liste yoksa uçlar
yoklanır, 403 = erişim yok). Veriler `/api/admin/chat` uçlarından gelir.

- Listenin başında **Üye mesajları** satırı ve raydaki bölümü; alt süzgeçler Takımlar / Oyuncular / Üyeler;
  okunmamış üye sohbetleri **Okunmamış** süzgecinde de görünür, aramada da bulunur.
- Sohbet aynı bölmede açılır: başlıkta takım / oyuncu / üye ve “Üye mesajı” etiketi; yazma alanı
  “ElitLig Yönetimi adına yaz…”; yanıt üyeye ElitLig Yönetimi adıyla gider, balonda yazan yönetici
  etiketlenir. Okundu ortak damgadır (bir yönetici okuyunca herkeste düşer). Tepki, yıldız, sabitleme,
  düzenleme, silme ve iletme bu sohbetlerde yoktur; `messages.reply` yetkisi yoksa yalnız okunur.
- Yalnız gerçek mesajlar: talep ve bildirimler sohbete düşmez (Talepler aracı ve üyenin bildirim merkezi).
- Okunmamış sayısı kişisel sohbetlerle birleşir (kenar çubuğu, Dock, menü çubuğu); üye yazınca liste
  canlı güncellenir, pencere arka plandaysa Mac bildirimi gelir.
- **Kayıtlar** (📞, `messages.calls_view`): üyelerle yönetim arasındaki aramalar; ses kaydı
  `messages.listen` yetkisiyle dinlenir.

## Saha ve maç planlama

Sitedeki **/editor/sahalar** (Saha ve Maç Planlama, çağrı merkezi) ekranının masaüstü karşılığı; aynı
uçları (`/api/match-requests/admin/*`) kullanır, site ekranı olduğu gibi çalışmaya devam eder. Görmek için
“Sahalar — görüntüle”, işlem yapmak için “Sahalar — yönet” yetkisi gerekir.

Üstte özet şeridi (yeni talep, bugün aranacak / geri dönülecek, bekleyen aday, bu hafta boş saat ve
prime-time boşluk, bu hafta maç), her görünümden takım arama (telefondaki takımın kartı açılır) ve
**Yeni talep** (maç talebi, görüşme, görev / not ya da doğrudan maç girişi). Dört görünüm:

- **Talepler.** Eski “Talepler ve görevler” ile “Bekleyenler” tek listede birleşti: uygulamadan gelen
  talepler, telefonla / elle açılanlar, karta bağlı olmayan saat havuzu adayları ve geri aramalar. Durum
  grupları: **Yeni** (henüz görüşülmedi), **Görüşülüyor / haber bekleniyor**, **Geri dönülecek**
  (tekrar aranacak, geri dönecek, düşünüp haber verecek; vadesiyle), **Eşleşmeye hazır** (istediği
  saatte rakip bekliyor ya da aday var), **Sonuçlanan** (kapalı, açılır). Her satır açmadan gösterir:
  kaynak rozeti ve ne zaman geldiği, takım (logo, ad, il, ara / WhatsApp), ne istediği (maç, belirli
  rakip, görüşme), istenen günler (Pzt…Paz), saatler ve sahalar, seçeneklerin uygunluk rengi (boş /
  aday var / rakip bekliyor / dolu), son görüşme etiketi + not + zaman, sıradaki iş (vade, “aranmalı”,
  “rakip hazır”). Süzgeçler: kaynak, saha, gün, saat aralığı, tür, durum, arama; sıralama (en yeni,
  vadesi yakın, en uzun bekleyen). Toplu işlem: haber bekleniyor, geri arama ata, olumsuz / reddet.
  Sistem önerileri (karta çevir, gizle, saati aç, havuza ekle) “Öneriler” düğmesiyle yanda açılır.
- **Talep ayrıntısı.** Başlıkta takım, il, toplam maç, sezon sayısı ve en çok oynadığı sezon; ara /
  WhatsApp / e-posta. “İstenen saatler” saha başına mini hafta tablosunda (istenen hücreler uygunluk
  rengiyle, diğer hücreler programdaki durumuyla); hücre seçilip **bu saatte maçı kur**, programda aç,
  başka saate taşı. Seçenek ekle / çıkar (saha tablolu seçici), haber bekleniyor, olumsuz sonuçlandı /
  talebi reddet / havuzdan çıkar, durum ve tür değiştirme, ayrıntılar (not, hatırlatma, öncelik), silme;
  maç ayarlandıysa maç ve görevliler. **Görüşme paneli** Projeler CRM'indeki gibi: kısa not + tek tıkla
  sonuç (Oynamak istiyor, Oynamayacak, Ulaşılamadı, Tekrar aranacak, Geri dönecek, Düşünüp haber
  verecek, Başka gün / saat istiyor, Mesaj gönderildi, Not), tarihli sonuçlarda hızlı zaman seçimi,
  görüşmeyi talebin bir saatine bağlama; altında görüşmeler, talep notları ve hareketlerden oluşan zaman
  çizelgesi. **Her görüşmenin etiketi, notu ve zamanı sonradan düzenlenir.** Takım notları da buradadır.
- **Program.** Saha sekmeleri (haftalık maç, boş saat, aday, doluluk %), hafta gezgini (“Bu hafta”,
  geçmiş haftalar), haftalık özet (maç, boş prime-time 20–23, toplam boş, bekleyen aday, rakip bekleyen,
  doluluk). **Hafta panosu:** günler sütun, saatler satır; büyük renkli hücreler (boş, müsait takım,
  aday sayısı + baş harfler, rakip aranıyor, maç alındı / takım adları, sistemde maç, dolu, oynandı,
  geçti), bugün sütunu ve şimdiki saat çizgisi, gün menüsü (günü dolu yap, dolu saatleri aç, kayıtlı
  maçları işle), “Saat seç” ile toplu dolu yap / aç. **Gün · tüm sahalar:** seçilen günde bütün sahalar
  yan yana. Saat paneli: havuz (iletişim, not, öncelik, taşıma, çıkarma / talebi reddetme), önerilen
  takımlar ve görüşme sonucu, takım ekleme, lig ve sezonla eşleştirip maçı oluşturma (fikstür), dolu
  yap / aç, saati boşaltma, sistemdeki maçı tabloya işleme. Geçmiş saat paneli skoru ve maç ekranlarını
  açar. Sahalar penceresinde saha ekleme, düzenleme, silme.
- **Takımlar.** Sekmeler: Tüm takımlar, Yeni kayıtlar (kayıt ili ve “x gün önce” öne çıkar), Son
  görüşülenler, Çok maç alanlar (toplam maça göre), Azalanlar, Güne göre, Esnek, Uzun süredir yok. Her
  satır: logo, ad, il, toplam maç, **en çok oynadığı sezon** (“2026 Güz · Ankara Süper Lig · 14 maç”),
  son maç ve oynama alışkanlığı, son görüşme, iletişim (satırda düzenlenir), talep aç. Süzgeçler: il,
  lig / sezon, sıralama, arama. **Takım kartı:** profil (il, toplam maç, sezon sayısı, en çok oynadığı
  sezon, son maç), iletişim, açık talepler, alışkanlık, önerilen saatler (havuza ekle), takım notları,
  havuz, uygulama talepleri, maçlar, müsaitlik ve düzenlenebilir görüşme geçmişi.
- **Kayıtlar.** Görüşmeler ve talep hareketleri günlere göre; tür, takım, saha, tarih süzgeçleri.
- **Çevrimdışı.** Talepler, program, takım listeleri ve takım kartları son eşitlenen hâliyle okunur.
  Görüşme kaydı ve düzenlemesi, saat, havuz, talep ve maç işlemleri kuyruğa alınmaz (saat ve talep
  durumları sunucuda birbirine bağlıdır); bağlantı yokken açık bir hata verir, hiçbir şey yarım kalmaz.

## Hesaplar ve virman

Elitlig'in muhasebe sistemlerinde kasa/banka hesabı kavramı yoktu. `elitlig-server`'a eklenen
`/api/finance` modülü kişisel, il ve Türkiye geneli kapsamlı hesaplar tanımlar. Bir hesap o defterin
bir ödeme yöntemine (ör. il defterindeki "Nakit") bağlanırsa ödenmiş kayıtlar bakiyeye kendiliğinden
yansır. Hesaplar arasında (ör. il kasasından merkez banka hesabına) virman yapılır; virmanlar
defterlerin gelir/gider toplamlarını bozmaz. Bu özellik sunucudaki değişiklik yayına alınınca çalışır.

- **Hesaba gelir / gider.** Her hesap kartının menüsünden (Gelir ekle, Gider ekle, Hareketler, Ekstre,
  Virman, Düzenle, Yetkiler, Arşivle) doğrudan kayıt girilir: tutar ya da tahmini tutar, durum (Tahmin,
  Bekliyor, Ödendi / Tahsil edildi), kayıt / vade / ödeme tarihi, kategori, cari, belge no. Yalnız
  ödenmiş kayıtlar bakiyeye yansır; tahmin ve bekleyenler kartta ayrıca gösterilir. Hareketler
  sekmesinde kayıtlar süzülür, tek tıkla ödendi yapılır, düzenlenir ya da silinir. Ön Muhasebe'de kayıt
  girerken hesap seçilirse kayıt yalnız o hesaba işlenir; Projeler'in bütçe kalemleri de seçilen hesaba
  düşer.
- **Hesap bazlı yetki.** “Yetkiler” penceresinde hesabın kimlere görüneceği seçilir: kapsam yetkisine
  göre ya da **yalnız seçilen kişiler**; listeye kullanıcı (aranabilir), rol ya da proje ekibi
  eklenir ve düzey verilir: Görüntüleyebilir, Kayıt girebilir, Yönetebilir. **Ortak / proje hesabı**
  (ör. “Elit Junior Cup kasası”) her zaman kısıtlıdır: yalnız açan kişi, admin ve yetki verilenler görür;
  bu hesaba yetkili kişi başka hesapları görmez. Kartlardaki menüler yalnız yetkinin izin verdiği
  işlemleri gösterir.
- **Çevrimdışı.** Hesap hareketi ekleme ve “Ödendi” yapma kuyruğa alınır; hesap açma, virman, yetki
  değişikliği ve kayıt silme bağlantı ister.

## Düzenli ödemeler ve bütçe

Muhasebe → **Düzenli Ödemeler**: sabit giderler ve tekrar eden ödemeler bir kez tanımlanır, her dönem
kendiliğinden takvime gelir.

- **Türler:** fatura (elektrik, su, doğalgaz, internet…), maaş, kira, abonelik, kredi / taksit,
  vergi / SGK, sigorta, düzenli gelir (aidat, sponsorluk) ve diğer.
- **Tekrar:** haftalık, aylık, 2 / 3 / 6 ayda bir, yıllık; süresiz, bir tarihte biten ya da taksit sayısıyla
  (ör. 24 taksit — “10/24”). Ayın 31'i gibi günler kısa aylarda ayın son gününe kayar.
- **Değişken tutar:** faturalarda tahmini tutar girilir; fatura gelince gerçek tutar yazılır.
- **Ödeme takvimi:** ay ay gezilir; her dönem için **Öde** (Ön Muhasebe'ye “ödendi” fişi düşer, seçili
  hesabın bakiyesine yansır), **Fatura geldi** (tutar + son ödeme tarihi → “ödenecek” fişi, sonra tek
  tıkla “Ödendi”), **Atla** ve **Geri al**. Önceki aylardan ödenmeyenler en üstte listelenir. Aynı dönem
  iki kez işlenemez. Tanım sonradan girildiyse geçmiş dönemler “gecikti” sayılmaz (isteğe bağlı).
- **Tanımlar:** aylık sabit gider dağılımı (türlere göre), sonraki vade, son ödeme, bu yıl ödenen;
  durdur / sürdür, kopyala, CSV.
- **Nakit akışı:** önümüzdeki 6 ayın beklenen gelir-gideri (düzenli ödemeler + Ön Muhasebe'deki vadeli
  alacak ve borçlar) ve kişisel hesap bakiyesinden başlayan dönem sonu bakiyesi.
- **Bildirimler:** hatırlatma süresine girince (varsayılan 3 gün önce), vade günü ve gecikince Mac /
  Windows bildirimi; ödenmeyen geciken ödeme 3 günde bir yeniden hatırlatılır. Bildirimler 09:00'dan
  önce gönderilmez; çok sayıda ödeme tek bildirimde toplanır. Menü çubuğu / görev çubuğu menüsünde ve
  Bugün ekranında geciken ve yaklaşan ödemeler görünür.
- **Çevrimdışı:** tanım ekleme / düzenleme / silme kuyruğa alınır; bir dönemi işlemek ya da atlamak
  bağlantı ister (sunucu çift kaydı önler).

Muhasebe → **Bütçe**: kategori başına aylık gider limiti ya da gelir hedefi. Gerçekleşen ve bekleyen
tutar Ön Muhasebe kayıtlarından hesaplanır; %85'i geçen kategori sarı, aşan kırmızı görünür. Son 3 ay
ortalaması ve bütçesi olmayan harcamalar (tek tıkla “Bütçe koy”) gösterilir.

Sunucu tarafı `elitlig-server` 'da (`/api/tools/recurring`, `/api/tools/budgets`); web sitesinde de
aynı bölümler vardır.

## Dosya Araçları

⇥ ya da 1–3 grup) ya da kutucuk menüsü: **Dönüştür**, **Araçlar**, **Dosya işlemleri**. Bırakırken ⇧
basılıysa Dönüştür, ⌘ (Windows: Ctrl) Araçlar, ⌃ (Windows: Alt) Dosya işlemleri çarkı doğrudan açılır.

  yüklü değilse ilgili araç "güncelleme gerekiyor" der, uygulamanın geri kalanı etkilenmez.

## Ekran Görüntüleri ve Pano

Aldığınız ekran görüntüleri ve kopyaladıklarınız bir yerde: **raflar** (⌃⌥T göster/gizle, ⌃⌥S arama
odaklı; her yerden) ve Görünüm → **Ekran Görüntüleri** kütüphanesi (⇧⌘P).

- **Toplama.** Ekran görüntüsü klasörü izlenir (Mac: Ekran Görüntüsü uygulamasının kayıt yeri,
  `defaults read com.apple.screencapture location`, yoksa Masaüstü; Windows: Resimler\Ekran Görüntüleri).
  En çok 3 ek klasör. Pano: kopyalanan **metinler ve bağlantılar varsayılan açık** (uygulama yeniden açılınca
  da durur), kopyalanan görseller isteğe bağlı; kütüphanenin ilk açılışında neyin toplanacağı sorulur.
  Parola yöneticilerinin gizli işaretlediği içerik (`org.nspasteboard.ConcealedType`, Windows
  `ExcludeClipboardContentFromMonitorProcessing` vb.) hiç okunmaz; uygulamanın kendi kopyalaması alınmaz.
  **Ekranı yakala** (⌃⌥A): işaretçinin altındaki ekran alınır, kırpma düzenleyicisi açılır.
- **Raflar.** Görseller, Metinler, Bağlantılar: ← → öğe, ↑ ↓ raflar arası, Tab raf, 1–9 numaralı kart,
  Boşluk önizle, ↩ kopyala ve kapat (odak önceki uygulamaya döner), ⌘C kopyala, P sabitle, F yalnız
  sabitlenenler, S raftan kaldır, ⌫ geri al, ⇧I / ⇧T / ⇧L raf gizle, ⇧S ara, L kütüphane.
- **Kütüphane.** Izgara / liste, sanal klasörler (iç içe), etiketler, ad ve not, sabitleme (⇧P klasöre koy),
  arama (metin, başlık, not, #etiket, bağlantı başlığı / alan adı), önizlemede yakınlaştırma (%400'e kadar),
  işaretleme (M) ve kırpma (C) — özgün görsel korunur, "Özgün görsele dön" —, dışa aktarma (⇧⌘E),
  başka uygulamaya sürükleme, çöp kutusu. Bağlantı kartları için başlık ve küçük resim isteğe bağlıdır.
- **Saklama.** Görsel / metin / bağlantı için 1, 3, 7, 15 ya da 30 gün (varsayılan 30). Sabitlenen, klasöre
  konan ya da etiketlenen öğe kalır; süresi dolan Çöp Kutusu'na, oradan 30 gün sonra silinir. Ekran
  görüntüsünün özgün dosyası klasöründe kalır.
- **Depolama.** Uygulamanın veri klasöründe (`shelf/`: JSON dizin, görsel kopyaları, küçük resimler).
  Hiçbir şey sunucuya gönderilmez. Görseldeki metni tanıma (OCR) bu sürümde yok.
- Başka modüller rafları `shelf:show` IPC kanalıyla açabilir (`window.elitlig.shelf.show({ search })`).

## Yayın Stüdyosu

Maçı Mac'ten canlı yayınlama (OBS benzeri): kameralar, ekran / pencere, skorbord ve tekrar tek bir
program görüntüsünde birleşir, YouTube'a (ya da herhangi bir RTMP / RTMPS sunucusuna) gider; gol
anında son ~10 saniye klip olarak kaydedilip oyuncunun profiline yüklenir. Yetki: `matches.live`.

- **Akış.** Arayüz programı `<canvas>`'ta oluşturur ve MediaRecorder ile (H.264/Opus Matroska ya da
  WebM) 250 ms'lik parçalar halinde ana sürece yollar. Ana süreçteki **ffmpeg** bunu yeniden kodlar:
  H.264 (VideoToolbox donanım kodlayıcı; açılamazsa x264), 2 sn'de bir anahtar kare, sabit bit hızı
  (CBR: `-maxrate` = `-b:v`, `-bufsize` = 2×), **sabit kare hızı** (`fps` süzgeci + `-fps_mode cfr -r`;
  MediaRecorder'ın değişken zaman damgaları YouTube'a düzensiz kare olarak gitmez), AAC 160 kbps
  **48 kHz** stereo (MediaRecorder Opus 48 kHz; yeniden örnekleme yok). Tek süreçte tee çıkışları:
  FLV → RTMP(S) (`flvflags=no_duration_filesize`), isteğe bağlı yerel tam kayıt (MKV) ve 2 sn'lik
  MPEG-TS parça halkası (son ~40 sn, geçici klasörde). Yayın adresi olmadan **yalnız kayıt** (prova)
  da çalışır. Giriş zaman damgaları korunur (`+genpts`); `-use_wallclock_as_timestamps` stdin'den
  topluca okunan parçalarda titreşim / ses kayması yarattığı için kullanılmaz.
- **Bağlantı (2.11).** Durum: hazırlanıyor → bağlanıyor → yayında (ya da kayıtta). RTMP çıkışı ffmpeg'in
  **fifo** katmanından yazılır: ağ yavaşlarsa kodlayıcı beklemez (~10 sn kuyruk; dolarsa kareler
  atılır, anahtar kareyle sürer, "ağ yetişemiyor" uyarısı), bağlantı koparsa ffmpeg **süreç yeniden
  başlamadan** 2 sn arayla 20 kez yeniden bağlanır — kayıt halkası, yerel kayıt ve tarayıcı
  kaydedicisi kesilmez; durum "yeniden bağlanıyor (kayıt sürüyor)" olur, bağlanınca "yayında"ya
  döner. Yayın anahtarı 3 kez reddedilirse, fifo'nun deneme hakkı biterse ya da kuyruk 30 sn dolu
  kalırsa (bağlantı askıda) süreç yeniden başlar: 2, 4, 8, 16, 16 sn arayla 5 deneme, sonra hata
  Türkçe gösterilir (bağlantı reddedildi, zaman aşımı, adres bulunamadı, yayın anahtarı, RTMPS,
  kodlayıcı). fifo'suz ffmpeg'de eski yol (RTMP düşünce süreç yeniden başlar). Yayın sürerken ekran
  uykuya geçmez; pencere arkada / örtülü / küçültülmüşken Chromium çizimi ve zamanlayıcıları kısmaz
  (`disable-renderer-backgrounding`, `disable-backgrounding-occluded-windows`,
  `disable-background-timer-throttling`; Windows'ta `CalculateNativeWinOcclusion` kapalı).
  RTMP protokol seçenekleri (`-rw_timeout`, `-rtmp_live`, `-rtmp_buffer`) tee yan çıkışlarına
  geçirilemediği için kullanılmaz; askıda kalan bağlantıyı fifo kuyruk denetimi yakalar.
- **Kararlılık (2.11).** 2.10'da yayının kopmasının başlıca nedenleri: (1) her açı tarayıcıda bir kez,
  ffmpeg'de bir kez daha kodlanıyordu — birkaç kamerada işlemci doyuyor, program kodlayıcısı gerçek
  zamanın gerisine düşüyor, stdin birikip (32 MB) ya da ilerleme 15 sn kesilip süreç yeniden
  başlıyor, RTMP bağlantısı her seferinde düşüyordu; (2) ağ takılınca tee FLV yazarken kodlayıcıyı
  da bekletiyordu (aynı yeniden başlatmalar); (3) her RTMP kopması süreci yeniden başlatıyordu.
  Şimdi: açılar kopya kipinde (aşağıda), RTMP fifo'da, takılma denetimi parçalar gelmeye devam
  ettiği sürece yeniden başlatmaz (yalnız arayüzden parça **ve** ffmpeg'den ilerleme gelmiyorsa;
  parçalar gelirken 60 sn hiç ilerleme yoksa kesin takılma). Bir açının takılması yalnız o açıyı
  etkiler; açı ffmpeg süreçleri düşük öncelikle (nice 10) çalışır. ffmpeg hızı 10 sn boyunca
  0,95'in altında kalırsa "slow" uyarısı verilir ve bir sonraki yeniden başlatmada daha hızlı ön
  ayar kullanılır (x264 veryfast → superfast → ultrafast; NVENC p4 → p2 → p1).
- **Yayın sağlığı (tanılama).** Her oturum `userData/logs/studio-<zaman>.log` dosyasına yazılır:
  seçenekler, ffmpeg komutları, ffmpeg uyarı / hata satırları, her yeniden başlatma ve nedeni,
  takılma / hız kararları, RTMP kopma / yeniden bağlanma, açı olayları (yayın anahtarı gizli; en çok
  8 MB, son 20 günlük saklanır). `studio.diagnostics()` → `{ logPath, lastErrors, ffmpegErrors }`,
  `studio.revealDiagnostics()` dosyayı Finder / Gezgin'de gösterir (kullanıcı gönderebilir).
- **YouTube.** Yayın adresi YouTube Studio'daki sunucu + anahtardır:
  `rtmp://a.rtmp.youtube.com/live2/<anahtar>` ya da `rtmps://a.rtmps.youtube.com:443/live2/<anahtar>`
  (sunucu uçları: `elitlig-server/docs/youtube-canli-yayin.md`).
- **Açılar (çok açılı kayıt).** Program akışına ek olarak her kaynak (kamera vb.) ayrı bir
  MediaRecorder akışıyla gelir; her açı için hafif bir ffmpeg (RTMP yok) 1 sn'lik parça halkası
  (~40 sn) yazar. **Kopya kipi (2.11):** kaynak `mimeType` H.264 ise
  (`video/x-matroska;codecs=avc1`, `video/webm;codecs=h264`; arayüz MediaRecorder'a
  `videoKeyFrameIntervalDuration: 1000` verir) görüntü yeniden kodlanmaz (`-c:v copy`,
  `h264_mp4toannexb`, parçalar anahtar karelerde bölünür); yalnız ses AAC'ye çevrilir. 720p'de
  işlemci süresi ~13 kat düşer (CI'da ölçülür). Kopya açılamazsa ya da kaynak VP8/VP9 ise eskisi gibi
  H.264'e kodlanır (kaynak boyutu, en çok 1080p; bilinmiyorsa 1280×720, ~3000 kbps, 1 sn'de bir
  anahtar kare). Programla aynı başlık kapısı, geri basınç, takılma ve kaydedici yeniden başlatma
  kuralları geçerlidir; yayın olmadan (prova / yalnız kayıt) da çalışır.
- **Yerel tam kayıt.** `start({ …, localRecord: { enabled, dir? } })`: maçın tamamı tee'nin üçüncü
  çıkışıyla `<klasör>/ElitLig-<maç>-<zaman>.mkv`'ye yazılır (Matroska: uygulama çökse de dosya
  açılır; her yeniden başlatma yeni parça, `…-2.mkv`). Durdurunca parçalar arka planda yeniden
  kodlamadan tek `+faststart` MP4'e birleştirilir, MKV'ler silinir (başarısızsa korunur). Durumda
  `localPath`, `localBytes`, `localRemux`; `studio:localRecord` olayı. Klasör `chooseRecordDir()`
  ile seçilir ve hatırlanır (varsayılan `~/Movies/ElitLig`, Windows'ta `Videolar\ElitLig`). Yerel
  çıkış yazılamazsa (disk dolu) yayın sürer, uyarı verilir.
- **Röportaj.** `interview.start({ matchId, label })` program parça halkasında o andan itibaren
  parçaları sabitler (halka ilerlese de silinmez); `interview.stop(id)` bunları yeniden kodlamadan
  `userData/interviews/interview-<maç>-<zaman>.mp4`'e birleştirir (H.264 düzeyi, `+faststart`,
  kapak). Yalnız kayıtta da çalışır; yayın durursa süren röportaj kendiliğinden yazılır (en çok
  90 dk). `interview.upload({ matchId, name })`: `POST …/matches/:id/interview/upload-url` → `PUT`
  (+kapak) → `POST …/matches/:id/interview { key, poster_key, duration_ms, width, height,
  size_bytes }` (sunucu adresi `matches.post_roportaj`'a yazar); ilerleme `studio:uploadProgress`
  (`kind: "interview"`). Uç sunucuda yoksa (404): "Sunucu güncellemesi bekleniyor: röportaj
  yükleme ucu henüz yayında değil."
- **LED çıkışı.** `studio.displays()` bağlı ekranları verir; `led.open({ displayId, mode, url?,
  matchId? })` o ekranda çerçevesiz, menüsüz, siyah, tam ekran bir pencere açar (Mac ve Windows).
  `mode: "web"`: `https://elitlig.com/led/<maç>` (ya da verilen adres; yalnız elitlig.com ve API
  kökeni, dış gezinme engelli, ön yükleme yok). `mode: "studio"`: uygulama arayüzü `#led-output`
  ile; stüdyo `led.sendState(state)` ile durumu yollar, LED penceresi `led.onState` / `led.getState`
  ile alır. Esc'ye iki kez basmak ya da `led.close()` kapatır; ekran çıkarılınca pencere kapanır ve
  durum (`led.onStatus`) yayılır.
- **Tekrarlar.** Gol ya da an: program ve seçilen açılar **aynı duvar saati penceresinden**
  yeniden kodlamadan kesilir (başlangıç anahtar kareye yuvarlanır: program 2 sn, açılar 1 sn;
  süreler ~0,5 sn içinde) → `userData/replays/<kimlik>/` (`program.mp4`, `angle-N.mp4`, her
  birine ~%40'taki kareden 640 px JPEG kapak, `replay.json`: etiket, tür, olay, oyuncu, dakika,
  özete dahil mi, yüklendi mi). 7 günden eskiler açılışta silinir (maç özetleri için), oturum
  sürerken hiçbir şey silinmez. Gol klibi (`saveClip`) artık program açılı bir tekrardır;
  `POST /api/admin/live-streams/matches/:id/clips?event_id=` ile gol olayına bağlanarak yüklenir
  (dosya + isteğe bağlı `poster` JPEG; en çok 40 MB; ağ hatasında bir kez yeniden denenir; eski
  sunucu `poster` alanını reddederse — 400/500 "Unexpected field" / `LIMIT_UNEXPECTED_FILE` —
  kapaksız bir kez yeniden gönderilir).
  24 saatten eski, eski biçim klipler (`userData/clips`) açılışta silinir.
- **Öne çıkanlar.** Arayüz videoyu ekran dışı canvas'ta gerçek zamanlı oluşturur; ana süreç
  parçaları ffmpeg ile H.264 High (yuv420p) + AAC, `+faststart` MP4'e kodlar
  (`userData/highlights/`; gerçek zamanlı kodlama başarısız olursa ham kopyadan x264 ile).
  Yükleme ön imzalı adresle: `POST …/matches/:id/highlight/upload-url` → dosya doğrudan depoya
  `PUT` (diskten akıtılır, ilerleme gösterilir; kapak da) → `POST …/matches/:id/highlight`.
  Silme: `DELETE …/matches/:id/highlight`. Uç sunucuda henüz yoksa (404): "Sunucu güncellemesi
  bekleniyor: maç özeti yükleme ucu henüz yayında değil."
- **H.264 düzeyi.** Yazılan her MP4'e (klip, tekrar, öne çıkan) çözünürlük / kare hızına uygun
  düzey yazılır (`h264_metadata` bsf; `app/studio/h264level.js`): 720p ve 1080p30 → 4.1,
  1080p60 → 4.2, daha büyük → 5.1+. Düşük düzey (ör. 1080p60'ta 4.0) sitede siyah görüntüye
  yol açıyordu.
- **Oynatma.** Klipler, tekrarlar ve öne çıkanlar uygulamada `elitlig-studio://clips/…`,
  `…://replays/<kimlik>/<dosya>`, `…://highlights/<dosya>` adresleriyle (Range destekli) oynatılır;
  yalnız bu klasörlerdeki beyaz listedeki adlar sunulur.
- **İzinler.** İlk kullanımda macOS kamera ve mikrofon izni ister; ekran / pencere paylaşımı için
  **Sistem Ayarları → Gizlilik ve Güvenlik → Ekran ve Sistem Sesi Kaydı**'nda Elitlig Araçlar açılmalıdır.
  Windows'ta sistem izni sorulmaz: kamera / mikrofon **Ayarlar → Gizlilik ve güvenlik → Kamera /
  Mikrofon → Masaüstü uygulamalarının erişmesine izin ver** ile yönetilir.
- **ffmpeg uygulamayla gelir.** `build/fetch-ffmpeg.js` FFmpeg 7.1.1'in statik arm64 ve x86_64
  derlemelerini (Martin Riedl FFmpeg Build Server, GPLv3, SHA-256 doğrulamalı) `build/ffmpeg/`'e
  indirir; electron-builder her mimariye kendisininkini koyar, universal birleştirme ikisini tek
  ikiliye (`Contents/Resources/ffmpeg/ffmpeg`) çevirir. CI paketli ikiliyle 3 sn'lik sentetik
  kodlama ve uçtan uca klip testi yapar. Geliştirmede `ELITLIG_FFMPEG=/yol/ffmpeg` ya da Homebrew
  ffmpeg'i kullanılır. Lisans metni: `Contents/Resources/ffmpeg/LICENSE.txt`.

## Panorama yayını

Yayın Stüdyosu'nun ikinci yayın türü: **maç seçmeden**, web sitesinin içerikleri ve 4-5 kamera açısıyla
stüdyo programı (Elitlig Panorama). İlk girişte "Maç yayını | Elitlig Panorama" seçimi gelir; seçim
hatırlanır (`studio.mode`), iki görünümün üst çubuğundaki "Maç yayını | Panorama" düğmesiyle değiştirilir
(yayın sürerken kilitli). Stüdyoyu önceden maç yayınında kullananlar doğrudan Maç yayınına girer.

- **Altyapı ortak, kopya yok.** Panorama açıları Maç yayınının sahne biçimine çevrilir
  (`renderer/src/lib/studio/panorama/model.js` `buildPanoramaScenes`) ve aynı karıştırıcı
  (`useCompositor`: ayrı iş parçacığı / ana iş parçacığı motoru, geçişler, siyaha geçiş), aynı kaynak
  altyapısı (`useStudioSources`, Kaynak ekle penceresi: kamera, ekran, pencere, görsel, video, renk,
  metin, saat, telefon, RTMP girişi…), aynı yayın motoru (`useEngine` → ana süreç ffmpeg → RTMP / RTMPS,
  prova / yalnız kayıt, yerel tam kayıt MP4), müzik çalar ve LED çıkışı kullanılır. Durum ayrı
  saklanır: `studio.panorama.v1` (kaynaklar, açılar, kart listesi, bant, tema, kapsam),
  `studio.panorama.prefs.v1` (kalite, geçiş, hedef, kayıt), `studio.panorama.templates.v1`.
- **Açılar (kamera düzenleri).** İçerik tam ekran · Tek kamera · Sunucu + içerik · Kamera + kart kutusu ·
  Sunucu + konuk · İki kamera + içerik · Izgara 2×2 · 2×2 + içerik · 2 + 3 · Büyük + küçükler (1 + 4) ·
  Şerit (5) + içerik · Üç kamera + içerik. Açı başına kaynak yerleri, içerik kartı, alt bant, künye ve
  isim bantları seçilir. Tık: önizleme, çift tık / `Shift`+sayı: doğrudan yayın, `1–9` önizleme,
  `Boşluk` / `Enter` GEÇİŞ (seçili geçiş türü), `C` kes; FTB düğmesi.
- **İçerik kartları (program tuvaline çizilir).** Puan durumu (sayfalı, form), fikstür, son sonuçlar,
  canlı maçlar ve skorlar (yoksa sıradaki maçlar), gol krallığı, asist krallığı, en değerliler (puan),
  haftanın enleri, haberler / duyurular (görsel + başlık + özet, döner), takım kartı, takım
  karşılaştırma, il / sezon özeti, sponsorlar, siteye bağlantı (QR), saat / tarih, serbest duyuru.
  Kartlar grafik katmanında çizilir (`lib/studio/panorama/draw.js`; `drawGraphics` panorama anlık
  görüntüsünü buraya yönlendirir): ana iş parçacığında da çizim işçisinde de aynı kod, yayına / kayda /
  LED'e giden görüntüde görünür (DOM kaplaması değil). Kart gövdesi önbellekli katmandır (saniyede bir
  ya da görsel yüklenince yeniden boyanır; kare başına ~0,5 ms). Görseller (armalar, oyuncu
  fotoğrafları, haber kapakları) medya vekiliyle yüklenir, işçiye `ImageBitmap` olarak aktarılır.
- **Oynatma listesi.** Kart başına süre (4–600 sn), otomatik döngü, elle sabitleme (`P`), ileri / geri
  (`←` / `→`), döngüden çıkarma, sıralama; kartta kalan süre çubuğu, uzun listelerde sayfalar kart
  süresine bölünür (en az 5 sn).
- **Künye ve alt bant.** Logo, program başlığı, il · lig · sezon, İstanbul saati ve tarih; kayan alt bant
  (canlı skorlar, son sonuçlar, yaklaşan maçlar, haber başlıkları, serbest metin; etiket ve hız);
  isteğe bağlı sponsor kutusu (sitenin sponsor kayıtlarından dönen logolar). Temalar Elitlig
  renkleriyle: Menekşe, Gece & Altın, Lacivert, Kağıt. 1080p30 (varsayılan), 720p30, 1080p60.
- **Şablonlar.** Hazır: Hafta değerlendirmesi, Canlı skor masası, Puan durumu özel, Haber bülteni
  (açılar + kart sırası + alt bant + tema). O anki düzen ad verilerek kaydedilir, uygulanır, silinir.
- **Veri.** Şehir (il), lig, sezon ve grup / etap seçilir; 45 sn'de bir tazelenir, hata olursa son
  sağlam veri ekranda kalır. Birincil kaynak sunucunun toplu ucu
  `GET /api/broadcast/panorama?cityId=&leagueId=&seasonId=&groupId=` (elitlig-server
  `routes/broadcastPanorama.js`; herkese açık, 30 sn önbellekli, yalnız sitede herkese açık bilgiler).
  Uç sunucuda yoksa (404) aynı veri sitenin herkese açık uçlarından kurulur: `/api/meta/*`,
  `/api/standings`, `/maclar`, `/api/players/statistics`, `/api/weekly-awards/public`, `/api/news`,
  `/public/sponsors`.
- **Yayın.** Hedef: YouTube yayın anahtarı (`rtmp://a.rtmp.youtube.com/live2/<anahtar>`) ya da özel
  RTMP / RTMPS sunucu + anahtar; "Prova / yalnız kayıt"; "Bu bilgisayara da kaydet" (klasör seçilir).
  Bağlantı, yeniden bağlanma, tanılama günlüğü ve sağlık göstergesi Maç yayınıyla aynıdır.

### Araç takımı paneli

Küçük, çerçevesiz panel; dışına tıklayınca gizlenir (iğne ile açık tutulur, Esc kapatır, ⌘1…⌘9 ilk
dokuz sekme; sekmeler yatay kayar, ↗ düğmesi aynı aracı tam sayfa açar). macOS'ta tüm masaüstlerinde
(Spaces) ve tam ekran uygulamaların üstünde açılır; açılırken gelen ara odak kaybı (menü çubuğu
menüsünün kapanması gibi) paneli artık hemen kapatmaz. Üstte hızlı işler: **Not / Görev** (Hızlı kayıt
penceresi), **Pano** (raflar, `shelf:show`), **Yakala** (ekran görüntüsü — Raflar'ın ⌃⌥A yakalaması,
`shelf:capture`; panel önce gizlenir), **Widget** (göster / gizle; hiç yoksa galeriyi açar), **Ekranı
uyanık tut** (süresiz, 30 dk, 1 sa, 2 sa — `powerSaveBlocker`) ve çalan müziğin mini denetimi. Sekmeler:

- **Düzen** — pencere düzeni ızgarası (aşağıda); panel açılmadan önce öndeki pencere taşınır.
- **Renk** — ekrandan renk alma (EyeDropper; Mac'te başka uygulamalardan renk almak için Ekran Kaydı
  izni gerekebilir), HEX / RGB / HSL / CSS kopyalama, tonlar, yazı karşıtlığı (WCAG), son renkler.
- **Hesap** — tek satırda hesap ve çeviri: `12*(4+3)`, `200*18%`, `5 km mi`, `3 saat dk`,
  `2 dönüm m2`, `72 f c`, `100 usd tl`; Enter sonucu kopyalar. Çevirici: para, uzunluk, ağırlık,
  sıcaklık, alan, hacim, hız, süre, veri. Döviz kurları (ECB / frankfurter.app, yedek open.er-api.com)
  6 saat önbelleklenir; bağlantı yokken son kayıtlı kur kullanılır.
- **Metin** — BÜYÜK / küçük / Başlık / Cümle düzeni (Türkçe i–İ, ı–I kurallarıyla), **Türkçe karakter
  düzelt** (UTF-8'in Latin-1 sanılmasıyla bozulan “Ã§ÄŸÅŸ” ve Windows-1254 karışması “Ýþð”),
  Türkçe karakter sil, slug, satır sırala / tekilleştir / ters çevir, boşluk temizle, sayım.
- **QR** — metin / bağlantı ya da Wi-Fi ağı; görseli kopyala, PNG / SVG kaydet (bağımlılıksız kodlayıcı:
  `renderer/src/lib/studio/qr.js`).
- **Saatler** — seçilen şehirlerin saati, tarihi, yerel saate farkı, gece / gündüz.
- **Sayaç** — Odak Sayacı'nı yönetir: 1–60 dk zamanlayıcı, kronometre (tur), pomodoro; süre menü
  çubuğunda görünür, bitince bildirim gelir.
- **Parola** — 8–64 karakter, küme seçimi, karışan karakterleri (I l 1 O 0) çıkarma, güç ölçer;
  parolalar yalnız bu bilgisayarda üretilir, saklanmaz.
- **Yüzde / KDV** — A'nın %B'si, A B'nin yüzde kaçı, değişim, artır / indir; KDV %1 / %10 / %20 dahil ↔
  hariç. Tevkifat, kredi, maaş gibi hesaplar için Hesap Araçları'na (⌘8) bağlantı.
- **Tarih** — iki tarih arası (takvim günü, hafta, yıl-ay-gün, **iş günü**: hafta sonu ve resmî tatiller
  — sabit tatiller + Ramazan / Kurban Bayramı 2025–2028; cumartesi iş günü seçeneği), tarihe gün / iş
  günü ekle-çıkar, **geri sayım** hedefleri (canlı).
- **Karakter** — Türkçe harfler, para ve semboller (₺ € © ® ™ ° …), oklar ve klavye işaretleri, spor /
  yayın, yüz ve iş emojileri; Türkçe adla arama, tıkla-kopyala, son kullanılanlar, biriktirme alanı.
- **Dolgu** — Lorem ipsum ya da Türkçe örnek metin; paragraf / cümle / sözcük.
- **JSON** — doğrula (hata satır / sütun), biçimle (2 / 4 boşluk, sekme), sıkıştır, anahtarları sırala.
- **Kodla** — Base64 (UTF-8 güvenli, URL güvenli), URL kodla / çöz, HTML varlıkları.
- **UUID** — sürüm 4, toplu (1–50), büyük harf / tiresiz.

Saf yardımcılar `renderer/src/views/toolkit/devTools.js`, `dateTools.js`, `chars.js`; araç listesi
`toolRegistry.jsx` (panel ve tam sayfa aynı bileşenleri kullanır). Testler `renderer/test/toolkit*.test.js`.

Kısayollar **Masaüstü araçları (⌘,)**'ndan değiştirilir (tıkla, tuşlara bas; ⌫ kapatır), tek tek
ya da hepsi varsayılana döner, tamamen kapatılabilir; başka uygulamanın tuttuğu kısayol “kullanımda”
diye gösterilir. Kenarlarda ve pencereler arasında isteğe bağlı boşluk (0–24 px) bırakılabilir.

- **macOS:** `osascript` ile System Events kullanılır; **Erişilebilirlik izni** gerekir (Sistem
  Ayarları › Gizlilik ve Güvenlik › Erişilebilirlik › Elitlig Araçlar). İzin yoksa uygulama izni ister
  ve Masaüstü araçları'nda Sistem Ayarları'nı açan düğmeyle uyarı gösterir; ilk kullanımda “System
  Events'i denetleme” (Otomasyon) izni de sorulur (`NSAppleEventsUsageDescription`). Betiklere yalnız
  doğrulanmış tam sayılar yazılır.
- **Windows:** bir kez başlatılan uzun ömürlü PowerShell süreci (Add-Type ile user32 / dwmapi:
  `GetForegroundWindow`, `GetWindowRect`, `SetWindowPos`, DPI farkındalığı, `DwmGetWindowAttribute`
  ile görünmez kenar payı); büyütülmüş pencere önce geri yüklenir, farklı DPI'lı ekrana geçişte ikinci
  turda düzeltilir. Not: bazı ekran kartı sürücüleri Ctrl+Alt+ok tuşlarını ekran döndürme için tutar;
  o durumda kısayol “kullanımda” görünür, Ayarlar'dan değiştirilebilir.
- Uygulamanın kendi pencereleri doğrudan (izinsiz, Electron `setBounds`) taşınır — her sistemde,
  Linux dahil (orada yalnız kendi pencerelerimiz). Pencerenin en küçük boyutu bölgeden büyükse
  (ana pencere en az 980 nokta) sağa / alta yaslı düzende pencere kenara geri itilir, ekrandan taşmaz.
- Pencereyi ekran kenarına **sürükleyince yapıştırma yoktur**: diğer uygulamaların sürüklenmesi
  Electron'dan güvenilir izlenemiyor; kısayol, menü ve ızgara kullanılır.
- Konum hesapları saf modülde (`app/windowLayouts.js`), betik üretimi `app/windowManager.js`'te;
  testler `app/test/windowLayouts.test.js`, `app/test/windowManager.test.js`.

### Uygulama geneli müzik çalar

Yayın Stüdyosu'nun müzik motoru (`views/studio/music/useMusicPlayer`: YouTube IFrame oynatıcısı,
oynatma listeleri, yerel dosyalar, geçiş) uygulamanın kökünde (`renderer/src/music/MusicProvider.jsx`)
ikinci kez, **ayrı bir listeyle** (`app.music.v1`) çalışır: görünüm değişince çalmaya devam eder.
Ses yalnız bu bilgisayardan çıkar, yayına gitmez. Müzik görünümünde (⇧⌘J) YouTube bağlantısı ya da
oynatma listesi eklenir, ses dosyaları seçilir ya da sürüklenir; “Stüdyo listesinden aktar” stüdyonun
listesini kopyalar. Denetim: kenar çubuğundaki mini çalar, menü çubuğu (Müzik), Araç Takımı menüsü,
araç takımı paneli ve klavyedeki **medya tuşları** (⏯ ⏭ ⏮; yalnız müzik çalarken tutulur, durunca
diğer uygulamalara bırakılır; Mac'te Erişilebilirlik izni gerekebilir).

**Stüdyo kuralı:** stüdyonun kendi müzik çaları yayına giden sesi yönetir. Varsayılan olarak genel
çalar Yayın Stüdyosu açılınca duraklar ve çıkınca (yalnız o duraklattıysa) sürer; Masaüstü araçları ›
Müzik'ten “Çalmaya devam et” seçilebilir. Stüdyonun listesi ve davranışı değişmez.

## Yönetim paneli (elitlig.com yönetiminin tamamı)

Kenar çubuğu → **Yönetim paneli** (⇧⌘L) web sitesindeki yönetim panelini uygulamanın içinde açar
(ayrı tarayıcı penceresi değil). Web'de rolünüz ve yetkilerinizle ne görüyorsanız burada da hepsi
var: maç, oyuncu, takım, lig, sezon, disiplin, içerik, sponsor, üye, yetki ve sistem ekranları.

- **Tek oturum**: uygulamaya giriş yeterlidir. Masaüstü jetonu panelin kendi oturum bölmesine,
  sayfa açılmadan önce aktarılır (adrese konmaz). Jeton yenilenince panel eşitlenir; uygulamada
  ya da panelde **Çıkış yap** denince ikisi birlikte kapanır ve panelin bu bilgisayardaki verisi
  silinir. Başka hesapla girişte panel temiz açılır.
- **Kenar çubuğu**: Yönetim başlığı altında web menüsünün bölümleri (Maçlar, Ligler, Takımlar,
  Oyuncular, Disiplin, İçerik, Üyeler, Yönetim ve ayarlar); bölüme tıklayınca sayfaları açılır.
  Liste web'in kendi menüsünden gelir ve yetkiye göre süzülür; izniniz olmayan bölüm görünmez.
  Web'e yeni bir yönetim sayfası eklendiğinde panel bir kez açılınca listeye kendiliğinden gelir.
- **⌘K komut paleti**: tüm yönetim sayfaları ve işlemler (Yeni maç oluştur, Kura çek, Haber
  yayınla…) adla, eski adla ya da eş anlamlıyla aranır; en az iki harfle **maç** (takım, lig,
  saha), **oyuncu** ve **takım** araması — sonuç tek tıkla ilgili yönetim sayfasını açar;
  "Maç listesinde ara" maç listesini o süzgeçle açar.
- **Menü çubuğu → Yönetim**: bölümler ve sayfaları, geri (⌘[) / ileri (⌘]), yeniden yükle, yeni
  pencerede aç, tarayıcıda aç, adresi kopyala.
- **Araç çubuğu**: geri / ileri / yenile, panel ana sayfası, düzenlenebilir adres yolu
  (`/editor/maclar` yazıp ↩), sayfada bul (⌘F), yazdır (⌘P), PDF olarak kaydet, indirilenler
  (dışa aktarımlar kaydet diyaloğuyla; ilerleme, aç, klasörde göster), yeni pencerede aç,
  tarayıcıda aç. ⌘R paneli yeniler.
- Dosya yükleme (fotoğraf, logo, belge) panelde olduğu gibi çalışır; site içi açılır pencereler
  uygulama içinde aynı oturumla açılır, site dışı bağlantılar sistem tarayıcısında açılır.
  Bildirim izni yalnız elitlig.com'a verilir.
- Web'in kişisel araç sayfaları (Araçlar merkezi, Ajanda, Not defteri, Muhasebe, Tablolar, Rehber,
  Ekipman, Hesap araçları, Odak sayacı, Mesajlar, Yapılacaklar, Talepler) panelde seçilince
  uygulamanın **yerel** aracında açılır (Yönetim → "Kişisel Araçları Yerel Uygulamada Aç" ile
  kapatılabilir).
- Panel internet ister: bağlantı yokken ya da site yanıt vermezken açıklayıcı boş durum ve
  **Yeniden dene** görünür; yerel araçlar çevrimdışı çalışmaya devam eder.

Web tarafı: gömülü panel `User-Agent`'ında `ElitligDesktopPanel/<sürüm>` imi ve
`window.elitligDesktopPanel` köprüsü bulunur (`elitlig-client` → `src/utils/desktopApp.js`,
`isDesktopPanel`). Bu modda menü kısılmaz (eski `ElitligDesktop/` "site penceresi" modu yalnız
iş akışı ve Araçlarım'ı gösteriyordu). Masaüstündeki yedek menü kopyası
`app/adminPanel/adminNav.snapshot.json` dosyasıdır; web menüsü değişince
`node scripts/sync-admin-nav.mjs ../elitlig-client` ile yenilenir.

## Oturum süresi

Uygulama girişte sunucuya `client: "desktop"` ve `X-Client-Platform: desktop` gönderir. Sunucu bu
girişlere 90 günlük jeton verir (`elitlig-server` → `routes/User.js`, `DESKTOP_SESSION_DAYS`).
Sunucudaki bu değişiklik yayına alınmadan önce jeton 24 saatliktir; uygulama jetonu süresinin
yarısı geçince yeniler, yine de 24 saatten uzun kapalı kalırsa yeniden giriş ister.

Oturum şu durumlarda kapanır: 90 gün dolunca, **Elitlig Araçlar → Oturumu Kapat** seçilince,
şifre değiştirildiğinde ya da hesap askıya alındığında.

## Geliştirme

```bash
npm install
```

```bash
npm start
```

```bash
npm test
```

Yapı:

- `app/`: Electron ana süreci. API istemcisi, çevrimdışı önbellek ve kuyruk (`api.js`), oturum
  (`session.js`), odak sayacı (`focus.js`), bildirimler (`reminders.js`), Mesajlar'ın canlı
  bağlantısı ve üye mesajları (`chat.js`, socket.io-client), yetkiler (`access.js`), pencereler,
  menüler, menü çubuğu ve Talepler özeti (`main.js`), Yayın Stüdyosu motoru (`studio/`: ffmpeg
  ikilisi ve komutları `ffmpeg.js`, süreç / yeniden bağlanma `engine.js`, klipler `clips.js`).
- `renderer/`: React arayüzü (Vite). `renderer/src/lib/sheets` içindeki formül motoru ve Excel
  dönüştürücüleri web sitesiyle (`elitlig-client`) aynıdır; testleri `renderer/test` altındadır.

Kurulum dosyasını macOS'ta üretmek için:

```bash
npm run dist
```

Windows kurulum dosyasını (NSIS `.exe` + `.zip`, x64) Windows'ta üretmek için:

```bash
npm run dist:win
```

`npm run ffmpeg:win` (= `node build/fetch-ffmpeg.js --platform win32`) yalnız Windows ffmpeg'ini
`build/ffmpeg/win-x64/` altına indirir; Mac ve Linux'ta da çalışır. Linux'ta
`npx electron-builder --win dir --x64` paketlenmiş klasörü üretir (NSIS kurulumu için wine gerekir).

Her push'ta GitHub Actions (`.github/workflows/build-mac.yml`) macOS'ta testleri çalıştırır, evrensel
`.dmg` ve `.zip` üretir, ad-hoc imzalar, uygulamanın çökmeden açıldığını ve paketli ffmpeg'in
(universal, VideoToolbox / x264, tee + segment) çalıştığını denetler. Aynı iş akışındaki Windows işi
`windows-latest` üzerinde testleri çalıştırır, NSIS kurulumunu ve zip'i üretir, kurulumu sessizce
(`/S`) dener, kurulan uygulamanın 20 sn çökmeden çalıştığını ve paketli `ffmpeg.exe`'nin (x264;
NVENC / QSV / AMF / MF yalnız uyarı olarak, H.264 seviyesi dahil) çalıştığını denetler. Son iş iki
platformun dosyalarını birlikte `package.json` sürümüyle adlanan GitHub Release'e yükler.
